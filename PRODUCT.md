# Product

## Register

product

## Users

Electronics engineers and hardware developers managing component procurement for PCB builds. They work with BOMs of 10–200+ line items, source from multiple distributors simultaneously, and make cost-sensitive decisions under lead-time pressure. They know Digi-Key and Mouser's interfaces well and are frustrated by them.

## Product Purpose

Kitted optimizes electronic component sourcing across distributors (Digi-Key, Mouser, Arrow, Newark, LCSC). It finds the minimum-cost distributor split for a given BOM — accounting for unit pricing, shipping, and order minimums — and surfaces alternatives for hard-to-find parts. Success means an engineer walks away with a purchase plan that saves money and ships faster than what they'd produce manually.

## Brand Personality

Sharp, minimal, pro. The tool respects the engineer's expertise: no hand-holding, no decorative chrome, no marketing language. Confidence is communicated through restraint and precision, not by adding more.

## Anti-references

- **Generic SaaS (Notion-ish)**: rounded corners, pastel accents, card grids, friendly icons. Kitted is not a productivity app.
- **Octopart / FindChips**: database-dump aesthetic, dense undifferentiated tables, no visual hierarchy. Data density without legibility.
- **Digi-Key's actual site**: cluttered legacy distributor UI, too many columns and options, zero confidence in the interface. Kitted is the tool engineers wish those sites were.
- **Crypto/Web3 dashboards**: glow effects, gradient cards, hero-metric templates. Dark for the sake of dark.

## Design Principles

1. **Precision over decoration** — every element communicates data or enables action. If it doesn't, it doesn't exist.
2. **Trust through restraint** — confidence comes from what's removed. The interface is an instrument, not a showpiece.
3. **Expert defaults** — the UI assumes the user knows what a BOM is. No onboarding tooltips on primary flows. Advanced options are accessible, not hidden.
4. **Information hierarchy beats visual hierarchy** — use scale, weight, and spacing to make data scannable. Color is reserved for state (error, success, active), not decoration.
5. **Dark is purposeful** — the dark theme serves focus in workshop and office environments. It is not aesthetic posturing.

## Accessibility & Inclusion

WCAG AA. Body text ≥4.5:1 contrast against background. Large text and UI components ≥3:1. Reduced-motion alternative for all animations. Keyboard navigable primary flows.
